Continuous Statistical Regression Testing for Generative LLMs

Large language models are probabilistic by nature. Traditional assertions break on random token noise, while naive benchmarks miss silent regressions. ProbEval gives you mathematical confidence in your LLM releases.

The Problem

Why Classical Testing Fails for LLMs

Deterministic unit tests assume f(x) == expected. In generative AI pipelines, this approach causes two critical issues:

01. Silent Regressions

Unintended Side Effects

Tuning a prompt for one customer edge case often degrades structured output validity or safety guardrails by 5–10% elsewhere in your dataset without throwing explicit runtime errors.

02. Sampling Jitter

Flaky CI Deployments

Temperature sampling and GPU floating-point non-determinism introduce variance. A single-sample test score of 91% today vs. 87% yesterday is usually random noise, not real degradation.

03. Evaluator Biases

Position & Length Bias

LLM judges systematically favor Option A over Option B by 10–20% regardless of quality. ProbEval applies bidirectional position swapping to eliminate false-positive wins.

Getting Started

Three Steps to Set Up

Get up and running locally or in your CI pipeline in under 5 minutes.

1

Install the package

$ git clone https://github.com/subasah/probabilistic-llm-eval-suite.git
$ cd probabilistic-llm-eval-suite && pip install -e ".[dev]"
2

Define your test benchmark (.jsonl)

{"id": "extract_01", "category": "extraction", "prompt": "Extract profile into JSON: Jane Doe, Lead AI Architect with 8 years experience.", "expected_schema": {"type": "object", "required": ["name", "role", "experience_years"]}}
{"id": "rag_01", "category": "rag", "prompt": "What is the primary regression mechanism?", "context": "The primary mechanism is continuous bootstrap testing.", "ground_truth": "Continuous bootstrap testing."}
3

Run an evaluation or regression gate

# Run benchmark suite with 5 samples per prompt
$ probeval run --benchmark structured_extraction --samples 5
# Compare candidate model against golden baseline
$ probeval compare --benchmark structured_extraction --regression-factor 0.10

System Design

Hierarchical Evaluation Funnel

To keep evaluation costs and latency minimal, ProbEval routes generated samples through a 4-tier funnel:

Tier 1

Deterministic Verification (<1 ms, $0 Cost)

JSON Schema validation, regex constraints, tool call signature verification, and latency SLA checks. Catches syntax breaks and malformed payloads instantly.

Tier 2

Semantic Similarity (<5 ms, $0 Cost)

Token F1 score (SQuAD precision/recall), normalized Levenshtein distance, and n-gram cosine similarity. Evaluates textual accuracy without requiring GPU embeddings.

Tier 3

RAG Triad Verification (<10 ms, $0 Cost)

Faithfulness checking (detecting claims unsupported by retrieved context) and answer relevance scoring. Flags hallucinations before invoking external judges.

Tier 4

Calibrated Model Judge (Optional)

Behaviorally anchored rubric scoring and pairwise comparison with bidirectional position swapping to completely neutralize position bias.

Automated CI/CD Quality Gate

GitHub Actions Workflow

Drop this into .github/workflows/llm_regression.yml to guard your main branch against silent model regressions.

name: LLM Continuous Regression Gate

on:
  pull_request:
    branches: [ main ]

jobs:
  eval-gate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
          cache: "pip"

      - name: Install dependencies
        run: pip install -e ".[dev]"

      - name: Run Unit Tests
        run: pytest -v tests/

      - name: Evaluate Regression Quality Gate
        run: |
          python -m probeval.cli compare \
            --benchmark structured_extraction \
            --regression-factor 0.05 \
            --samples 6 \
            --html reports/ci_regression_report.html

      - name: Save HTML Benchmark Artifact
        uses: actions/upload-artifact@v4
        if: always()
        with:
          name: regression-report
          path: reports/*.html
